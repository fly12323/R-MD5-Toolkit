# R 品牌图标

`r-icon.png` 是通过内置 image_gen 工具生成的透明背景原图。
`r-icon.ico` 是该图的 Windows ICO 编码，包含 16、24、32、48、64、128、256 像素尺寸。
图标用于侧栏品牌、窗口标题栏、任务栏和 EXE 文件图标。

最终生成提示词：

> Create a single polished Windows desktop application icon for a developer MD5 utility named R. One iconic uppercase Latin letter R, immediately legible at 16 and 32 pixels, centered within a precisely rounded square badge. Visual identity: deep ink-blue #192C49 badge, porcelain white bold geometric R, one restrained cobalt-blue #4169E1 inlay in the diagonal leg suggesting two streams converging. Solid architectural silhouette with a subtle refined dimensional bevel, crisp edges, premium professional desktop software aesthetic. The R must dominate 70% of the badge, generous balanced optical margins. Front-facing orthographic view. No padlock, shield, hacker imagery, neon, circuits, surrounding text, mockup, scenery, drop shadow outside badge, or multiple icons. Output one square high-resolution icon with genuinely transparent background outside the rounded square badge, centered and cleanly isolated. This is the final app icon, not a UI screenshot.
